A
对话流 + 进度侧栏
最稳妥的 SaaS 范式：左侧题目进度与画像，中间气泡对话流，底部作答框。AI 把评分要点（rubric）摊在问题里，信息层级清晰、上手零成本。
经典 · 稳对话气泡进度可见

优势
认知负担低、求职者熟悉，对话历史完整可回看，rubric 透明。
取舍
底层 harness 的"工程味"被隐藏，演示架构卖点时不够直观。
适合
面向求职者的正式产品主线，追求信任感与可用性。
B
聚焦单题 + Harness 实时可视化
左侧极简时间线，中间只聚焦当前一道题，右侧深色 Runtime 面板实时显示 PEV 相位、Examiner / Grader 子 agent、记忆事件与上下文窗口占用——把"模型外的工程"全摊开。

优势
直接展示架构卖点（PEV / 子 agent / 五层压缩 / pinned），单题聚焦减少干扰。
取舍
信息量大，对普通求职者偏"重"，更像开发者 / 演示视角。
适合
技术评审、作品集 Demo、面试讲解 harness 工程时。
C
沉浸式面试间
深色环境 + 有人设的 AI 面试官「Forge」，呼吸光圈与"正在追问"状态营造真实面试临场感，问题居中放大，玻璃质感作答框支持语音。弱化仪表盘，强化对话氛围。

取舍

适合
