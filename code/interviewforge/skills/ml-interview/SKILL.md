## 岗位画像
- **典型赛道**：搜推广 / CV / NLP / 大模型 / 量化 / 风控
- **职级分层**：
  - 初级：能跑通模型 + 调参 + 看懂论文
  - 中级：能独立做业务模型、做特征工程、做线上 A/B
  - 高级：能主导一个方向、设计模型架构、写出可发表论文
- **核心区别于纯算法岗（leetcode 岗）**：考察的是「模型 + 数据 + 业务理解」的综合能力，不只是写算法题

## 考察维度

### 1. 数学与机器学习基础（权重 20%）
- **概率统计**：贝叶斯、最大似然、假设检验、Bias-Variance 分解
- **线性代数**：矩阵分解（SVD/PCA）、特征值、范数
- **优化理论**：凸优化、梯度下降族（SGD/Adam/AdamW）、学习率策略
- **泛化理论**：过拟合/欠拟合、正则化（L1/L2/Dropout/BN）、交叉验证
- **常见模型**：LR / SVM / GBDT / XGBoost / LightGBM 原理与差异

### 2. 深度学习（权重 25%）
- **网络结构**：CNN / RNN / Transformer / Attention 原理
- **训练技巧**：BatchNorm vs LayerNorm、残差连接、梯度消失/爆炸
- **优化器**：Adam 内部机制、warmup、cosine schedule
- **分布式训练**：DP / DDP / ZeRO / 模型并行 / 流水并行
- **PyTorch 内部**：autograd 机制、动态图 vs 静态图

### 3. 业务建模（权重 25%）
- **特征工程**：连续特征分桶、类别特征 embedding、交叉特征、特征筛选
- **样本构造**：正负采样、Hard Negative Mining、样本权重
- **评估指标**：AUC / GAUC / Recall@K / NDCG / BLEU / 业务指标对齐
- **A/B 实验**：分桶、显著性、长期效应、辛普森悖论
- **召回-粗排-精排-重排** 四阶段架构（搜推广必考）

### 4. 大模型/LLM 方向（权重 25%，岗位相关时）
- **Transformer 细节**：MHA / RoPE / KV Cache / FlashAttention
- **预训练范式**：因果 LM / 掩码 LM / Prefix LM
- **微调技术**：SFT / LoRA / QLoRA / DPO / RLHF（PPO 流程）
- **推理优化**：量化（INT8/INT4）、KV Cache 复用、Speculative Decoding、vLLM PagedAttention
- **评测**：MMLU / HumanEval / Arena Elo、自动化评测的陷阱
- **Agent / RAG**：检索增强、工具调用、上下文工程

### 5. 工程能力（权重 5%）
- 写 PyTorch 训练循环（含 amp/checkpoint）
- 数据 pipeline（Dataset/DataLoader/采样）
- 线上服务（torchserve/triton/onnx）

## 出题节奏（建议 60 分钟）
1. **基础理论（10 min）**：抽 1-2 个核心概念（如 BatchNorm 推理时为什么用滑动平均）
2. **模型原理（15 min）**：让讲一个核心模型的内部（Transformer 推导 attention）
3. **业务深挖（20 min）**：给一个业务场景让设计模型 + 评估方式
4. **项目（15 min）**：让讲一个简历项目，深挖到「为什么这么做、效果数字、对照基线」

## 经典深挖点

| 主题 | 必考追问 |
|---|---|
| **Transformer** | 为什么除以 √d_k？多头的意义？为什么 LayerNorm 而非 BatchNorm？ |
| **BatchNorm** | 训练和推理为什么行为不同？小 batch 怎么办？ |
| **GBDT vs LR** | 各自的偏好场景？连续 vs 离散特征哪个更适合谁？ |
| **AUC** | 物理意义？为什么对正负样本比例不敏感？GAUC 解决什么问题？ |
| **过拟合** | 怎么判断？防止过拟合的 5 种方法各自适用场景？ |
| **RLHF** | 为什么不直接用 SFT？PPO 的 reward model 怎么训？ |
| **LoRA** | 为什么有效？秩 r 怎么选？哪几层加？ |
| **A/B 实验** | 样本量怎么算？分桶怎么避免污染？长期效应怎么看？ |

## 追问树

### 答得好 → 持续加压
- 「这个 trick 在你业务上离线提升 X%，上线了吗？线上是多少？为什么差距大？」
- 「你这个方案对比 SOTA 差多少？差在哪？」
- 「假设 GPU 资源砍一半，你的训练方案怎么改？」

### 答得卡 → 给推导抓手
- 「先从 1D 写起，再扩到 2D / 多头」
- 「假设是二分类，你的 loss 怎么写？」

### 答得套话 → 要论文/数字
- 「这个结论你是从哪篇论文看到的？」
- 「你模型上线后 CTR 提升 X%，怎么排除运营/活动影响？」

## 红旗信号

| 信号 | 含义 |
|---|---|
| **只会调包** | sklearn/transformers 用得溜但讲不清原理 |
| **指标背诵** | 能列十几个评测集但没真正调过模型 |
| **数学盲** | 推导 LR loss 都推不清楚 → 基础不牢 |
| **不看论文** | 大模型方向但不知道近半年的关键工作 |
| **业务脱节** | 离线 +5% 但讲不清线上影响、A/B 怎么做 |
| **过度自信** | LLM 半年经验自称「主导」→ 必须深挖项目 |

## 评分 rubric（每维度 1-5 分）

| 分 | 描述 |
|---|---|
| 1 | 推不出基础公式或概念错误 |
| 2 | 会用库但讲不清原理 |
| 3 | 能讲清模型原理 + 调参经验 + 业务指标 |
| 4 | 能识别问题瓶颈、能讲多方案 trade-off、读过关键论文 |
| 5 | 能主导一个方向、有可发表/开源/上线规模成果、能讲清前沿动态 |

**通过线**：中级 3.0+；高级 3.5+ 且业务建模或大模型方向至少 4+。

## 与简历交叉验证清单
- 简历写「负责 X 模型，提升 Y%」→ 必问基线、对比方案、上线效果
- 简历写「Kaggle 金牌」→ 让讲一道复盘，看细节
- 简历写「精通 PyTorch」→ 让手写一个 MultiHeadAttention forward
- 简历写「大模型微调」→ 必问数据规模、训练资源、评测方式、踩过的坑
